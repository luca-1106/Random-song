Hoe wil je koppelen?

of
Ingebouwde Muziekmix-koppelingActief

Gebruik deze alleen als je weet dat jouw Spotify-account hiervoor toegang heeft.

Stel je eigen Developer-koppeling in Je hoeft niets te bouwen. Je registreert alleen de koppeling bij Spotify.
  1. Open Spotify for Developers Klik op Create app en selecteer Web API en Web Playback SDK.
    Open Dashboard
  2. Voeg de Redirect URI toe Kopieer deze exact, voeg hem toe bij de Redirect URI's en sla je Spotify-instellingen op.
  3. Koppel je Client ID Kopieer de Client ID uit je Spotify Developer-omgeving en plak hem hieronder.
  4. Log in bij Spotify Daarna log je in met het Spotify-account waarmee je Muziekmix wilt gebruiken.
Developer-koppeling delen met iemand anders

Voeg die persoon eerst toe in Spotify en deel daarna alleen je Client ID.

  1. Open je koppeling in het Spotify Developer Dashboard.
  2. Ga naar Settings → Users Management → Add new user.
  3. Vul naam en Spotify-e-mailadres van die persoon in.
  4. Deel je Client ID. Die persoon kiest daarna optie 1 in Muziekmix.

Een Development Mode-koppeling ondersteunt maximaal 5 geautoriseerde gebruikers.

Gebruik alleen een Client ID. Vul of deel nooit een Client Secret.
