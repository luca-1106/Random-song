2

Gebruik je eigen Spotify Developer-app

Heb je geen Developer-koppeling van iemand anders? Maak dan zelf een Spotify Developer-app.

  1. Open Spotify for Developers Maak een app aan en selecteer Web API én Web Playback SDK, of open je bestaande app.
    Open Dashboard
  2. Voeg deze Redirect URI exact toe Plak hem bij de Redirect URI's van je Spotify-app en sla de instellingen op.
  3. Plak je Client ID in Muziekmix Je vindt de Client ID in je Spotify Developer-app.
  4. Koppel Spotify Log daarna bij Spotify in met het account waarmee je wilt spelen.

Gebruik alleen je Client ID. Vul of deel nooit een Client Secret.

Wil je jouw Developer-koppeling ook met iemand anders delen?

Voeg die persoon eerst toe in Spotify en stuur daarna alleen je Client ID.

  1. Open je app in het Spotify Developer Dashboard.
  2. Ga naar Settings → Users Management → Add new user.
  3. Vul de naam en het Spotify-e-mailadres van die persoon in.
  4. Stuur daarna jouw Client ID. Die persoon gebruikt vervolgens optie 1 in Muziekmix.

Een Development Mode-app kan maximaal 5 geautoriseerde gebruikers hebben.
